Rules applied:
- Candidates come from five sources: country layer (Canada Day, Black Friday,
  Canadian Thanksgiving, Holiday Season) + audience cultural layer (Spring
  Festival, Lantern Festival, Women's Day, Children's Day, 618, Mid-Autumn,
  Double 11, Double 12) + season-anchored (none — no strong season) + user
  dates (none) + expo / booth opportunities (see Brand-exposure prompts below
  — no city given, so no local expo candidates in this table).
- Every candidate has a "why it fits" tied to the user's specific answers.
  No generic industry labels.
- Past campaigns filtered the list: Double 11 ran in 2026 with a weak result,
  so it enters the candidate table with a changed-angle note — a weak past
  result changes the angle; it does not auto-veto a major festival.
- Do not rank by "expected performance" — the skill does not predict performance.
