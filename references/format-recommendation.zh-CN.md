# 形式推荐——目标优先 + 约束过滤

skill 如何为每个活动推荐 2–3 种活动形式。推荐来自一串漏斗问题（见 `templates/intake.md` Stage 2），不是按行业查表——“零售”太宽泛，定不了形式（母婴零售 ≠ 露营零售 ≠ 茶零售）。

## 第一步——目标 → 候选形式（目标是首要键）

| 目标（漏斗 F1） | 候选形式 |
|---|---|
| 清库存 / 季末 | 清仓、买一送一、组合装 / 礼盒（走量） |
| 拉新 | 抽奖、联名 / 合作、快闪 / 试吃（试用带动拉新） |
| 提高客单价 | 满赠、组合装 / 礼盒 |
| 新品发布 | 发布活动、预售、试吃 / 试用 |
| 复购 / 留存 | 集点 / 会员卡、组合装 / 礼盒（囤货装） |
| 送礼场合 | 组合装 / 礼盒、满赠 |
| 引流 / 曝光 | 快闪 / 店内活动、抽奖、联名 / 合作 |

## 第二步——约束过滤（排除）

把每个过滤器应用到第一步的候选形式上。过滤器只排除，永远不编造形式。

| 漏斗答案 | 过滤器 |
|---|---|
| 渠道 = 仅线上（F5） | 排除快闪 / 店内活动、店内试吃 |
| 预算 = 低预算带（F6） | 排除快闪（贵）、大奖抽奖。优先折扣码、集点、小奖抽奖 |
| 毛利 = 薄（F3） | 排除深度折扣。优先满赠、买一送一（成本可控） |
| 价格 = 高单价（F2） | 优先预售、发布活动、联名（建立信任）。避免闪电折扣 |
| 购买频次 = 一次性（F4） | 排除集点 / 会员卡（没有复购可奖励） |
| 购买频次 = 重复购买（F4） | 集点 / 会员卡和囤货组合装保留 |
| 产品不可试（从 Stage 1 产品品类推断，例如服务、无形产品） | 试吃不适用——在形式列表允许的情况下换成免费试用 / 免费咨询 |

## 第三步——输出

- 推荐 **2–3 种形式**，每种附一句话理由，理由必须引用使用者的具体答案（目标 + 价格 + 毛利 + 频次 + 渠道 + 预算）。
- 永远不要写通用理由（“这个很流行”、“最佳实践”）。如果理由引用不了使用者答案，这个形式就不推荐。
- 使用者选、混搭，或者用自己的想法覆盖。使用者自己的想法永远优先——推荐只是选项，不是结论。
- 推荐的形式可能增加物料（例如试吃 → 样品；快闪 → 易拉宝）。物料清单会自动接上。

## 规则

- 任何漏斗问题都可以跳过 → skill 不用该项过滤，并在报告里把缺失的输入标为假设。
- “不确定”= 该问题无约束（等同于跳过）。
- “其他（自己输入）”的答案按原样使用——skill 按它们推理，永远不强行塞进固定选项。
- 预设（`references/activity-format-presets.md`）是菜单；本文件是挑菜单的逻辑。预设是起点，不是经验证有效的赢家。
- 永远不要把推荐的形式说成效果承诺。
