# 数据收集与留存清单

目的：在活动进行中收集数据，这样活动后的报告 / 复盘才有东西可报。进行中没收集 = 之后没得复盘。

## 负责人

每个活动指定一名每日数据收集人（intake 项）。他们在活动的每一天填每日日志——不是之后补。平台会重置、后台会变、记忆会淡。

## 留存规则

- 保留原始导出（CSV / 后台导出），不要只留后台截图。截图是证据；原始数据才是复盘计算的依据。
- 一个活动一个文件夹。文件命名：`YYYY-MM-DD_<指标>_<来源>`。
- 在活动期间每日收集。不要等到之后。
- 复盘完成前不要删除原始数据。复盘后归档（不要删除）——下一个活动可能需要基线。
- 如果某项指标没收集，在日志里标“not collected”。不要事后凭记忆重建。

## 隐私与同意（加拿大）

- 报名表（邮件 / 短信）必须包含同意勾选——商业电子信息需要按 CASL 获得同意。
- 客户照片（打卡墙、活动照片）在用于任何活动后物料之前，需要本人同意。
- 只收集复盘需要的数据。不要多收个人数据。

## 数据流向——活动后跟进

跟进清单（活动后要整理什么 + 报告什么）见 `references/post-campaign-followup.md`——只列项，不写操作。

复盘本身（分析、结论、建议）是另外一个（未来的）skill。本 skill 准备数据 + 跟进清单，让复盘 skill 拿到它需要的一切。它不做复盘。
