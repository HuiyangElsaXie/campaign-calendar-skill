# 营销物料清单

## v1.1.0 结构化约束（优先于旧数量默认）

使用 [结构化计划](../references/structured-plans.zh-CN.md) 和 [内容矩阵](../references/content-matrix.zh-CN.md)。复用已知输入；人数不换算 FTE。独立主题、平台改写分开，数量由必要问题覆盖和工时决定，下列旧数量仅供条件选项，不自动采用。七个完整年份日期分开，素材完成早于预热。预算/容量未知须保留；所有选中 ID、详情、节点、来源及结束标记均需 verify；候选合作不混入正式日历。

时间线的逐活动附件。时间线说什么时候；这份清单说什么、多少件、截止到什么时候。它不写创意内容。

## 与活动策划 skill（06）的边界

- 这份清单：什么 + 多少件 + 截止到什么时候 + 成本依据（数量 × 单价）。
- 06（执行简报）：每件物料的创意怎么做——信息、设计规格、实际文案。
- 文案矩阵：本 skill 决定是否需要，并统计文案件数。矩阵内容（实际文案）属于 06 / 文案 skill。

## 数量（默认值——使用者可以改任何一项）

默认值是规划默认值，不是标准。使用者没有确认的每一项默认值，在输出里都要标为默认值。

| 渠道 / 物料 | 默认数量 | 备注 |
|---|---|---|
| 社媒账号 | 每账号 2 件（feed + story） | 按平台算。使用者可改拆分。 |
| 网站 | Hero 横幅 + 落地页横幅（没有落地页则为 1） | |
| 实体门店 | 每门店 2 张海报（橱窗 + 店内） | |
| 文案件数 | 1 条核心信息 + 每渠道 1 条改编版 | 只计数，不写。内容是 06 的工作。 |
| 文案矩阵 | ≥ 2 个平台 / 渠道时建议做 | 1 条核心信息 × 每平台改编版。内容是 06 的工作。 |
| 易拉宝 | 每地点 1 个——仅限有线下实体存在的店内活动 / 快闪 / 地推 | 否则：不需要。永远不要默认成需要。 |
| 线下分发海报 / 传单 | 分发目标 + 10% 缓冲 | 仅限分发 / 地推。没有目标 → TBC。 |
| 地推小礼物 | 预估人流 × 领取率 | 仅限带人流的地推。两个输入都由使用者提供；未知 → TBC。永远不要编造人流或领取率。 |

## 使用阶段

每件物料都标上使用阶段：

- **预热**：预告 / 即将上线类物料（最先制作，从预热开始时使用）。
- **大促**：优惠类物料（在大促窗口内使用）。
- **两者**：跨预热和大促使用的物料（例如店内橱窗海报）。

制作截止日已经保证所有物料在预热开始时准备就绪（见 `lead-time-rules.md`）。阶段标签告诉使用者哪些物料最先重要，不是另外的制作日期。

## 复用

可直接使用的复用物料记为 0 件新增；逐项列出复用了什么，需要改尺寸、翻译、适配或审阅时仍计工作量。复用在 Stage 2 intake 里按活动决定（Q12）。如果使用者没有提供复用信息，就假设没有复用，并说明。

## 条件问题（intake）

只在适用时问——都属于同一批 intake：

- 线下实体存在？（店内活动 / 快闪 / 地推 / 无）——决定易拉宝、传单、礼品、QR。
- 分发目标（户数 / 人数）——决定传单数量。
- 预估人流 + 领取率——决定礼品数量。
- 单价已知？（每项）——决定预算表能否合计。
- 物料总预算上限？——如果给了，清单会核对总计 vs 上限并标超支。

## 成本工作表（在详细报告里）

记录币种，以及每个上限覆盖仅物料还是全活动。

| 成本范围 / 项目 | 数量 | 使用者单价 | 行总计 | 完整性 |
|---|---|---|---|---|
| 物料 | … | 已知或 TBC | 数量 × 单价 | 已知 / TBC |
| 物料小计 | | | … 或 TBC | 仅部分成本范围 |
| 其它必要成本 | … | 已知或 TBC | … 或 TBC | 适用的投放、展位、运输、人力、费用等 |
| 全活动成本 | | | … 或 TBC | 完整 / 不完整 |

- 不编价格；只有预算上限也算不出总成本。
- 物料数量留在本清单；非物料成本用一行汇总即可支持完整比较，不在物料清单内不等于零。
- 只比较同币种、同范围成本，不静默换汇。开放预算带或不确定没有数值上限；有界范围也只有使用者明确时才把上界当上限。
- 完整总额与明确且同范围上限比较，才报 OVER / WITHIN。必要成本未知时，列已知小计及 TBC 项，说明总预算检查未完成，不宣称全活动 WITHIN。
- 已知必要成本小计已超同范围上限时，即使总额未齐，也能说明至少 OVER；成本不完整永远不能证明 WITHIN。
- 有上限时，同时检查逐活动与总跨度；复用 / 适配费用及共享费用在注明的依据上只计一次。
