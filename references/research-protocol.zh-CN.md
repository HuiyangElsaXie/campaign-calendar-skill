# 研究协议——日期证据

研究在第一阶段补日期，不编产品、受众、业务阶段或季节。已有业务事实直接复用；与本次明确更正冲突时，只澄清冲突点，不悄悄拼接。

## 日期归属与可信度

- **user-set**：使用者自定的年庆 / 活动日期，直接采用，不外部查证；只校验日期格式与范围。
- **使用者转述的公共日期**：使用者提到的外部活动 / 假期日期，保留转述来源；查证前标 **unverified**，不是官方事实。
- **base-listed**：现成核对清单中的日期 / 规则，**不等于**目标年份发生日或当地 observance 已核验。
- **government-sourced**：已打开适用政府来源，读到目标年份日期。
- **official-announcement**：已打开责任主办方 / 零售商来源，读到本届日期 / 窗口。
- **unverified**：当年证据不足、来源冲突或无法核验。TBC 是合法结果。

使用者可以接受未核实公共日期用于条件性草稿，但保留标签和依赖；选择或关口 2 都不能把它升级成官方 / 已核实事实。

## 何时研究、研究什么

没有现成层的国家、相关文化日期、公告窗口、本地机会、凭记忆提出的日期都要研究。现成层的各年 / 各地发生日在核验后才可升级标签。法定假日与商业锚点不同；是否纳入要看具体业务 / 受众理由，不只看是否法定。

## 来源与流程

1. 搜目标年份 / 届次及地区，打开页面阅读；搜索摘要不等于证据。
2. 法定日期 / observance 用政府日历；活动及促销窗口用主办方、联合会、零售商页面；商业日期用相关已发布年历。法定假日表不能验证所有零售纪念日。
3. 农历 / 可变日期记录规则，并核对两个一致的独立可靠来源；不跨国照抄农历发生日。
4. 本地活动用有日期的市政府、BIA、社区主办方列表；避开内容农场、AI 清单、无日期页面、未核实转发。去年办过只是历史线索，不证明周期或本届会办。
5. 来源冲突时展示冲突、保留未核实，请使用者决定接受哪项规划假设；没有可靠结果则 TBC / unverified。

每个研究日期记录**活动 / 年份、准确日期或窗口、地区 / 时区、来源 URL（或用户提供的来源标识）、页面注明的发布 / 更新日、查阅日、可信度**。没有标明发布日期时不编造。用候选 ID 关联来源列或脚注。活动举办日的证据不等于展位可用、报名资格、价格或申请截止的证据。

研究建立的国家层使用前给使用者确认，并标 research-built。使用者自己的业务事实无需外部信源；不复用其它客户的私有数据。

## 离线 / 工具不可用

使用现有搜索工具，不假设必须有浏览器或付费服务。无法研究时说明限制，仅把已有来源或 base-listed 规则当作 **unverified / TBC** 的当年发生日。缺失日期影响选择时请使用者提供；不把历史抽查或记忆升级成当年已核验。无网络是受支持的条件性草稿路径，不是编造证据的许可。
