# Coverage-led content matrix

Reuse the user's business, audience, channels, earlier decisions and corrections before asking anything. Selected campaign IDs own scope. Separate independent core themes from platform variants; platform count does not multiply research jobs. This skill plans themes and briefs; actual copy, design and publication are separate deliverables.

For each campaign first identify audience questions and evidence gaps. For each core record pillar, audience, problem, subtopics, asset type, purpose, funnel stage, CTA/destination, primary channel, reuse plan, release order, delivery/release date, role and claim requirements. Link coverage IDs and source IDs. A variant points to one core and explains channel-specific form/length/CTA adaptation. A materially new question requiring new research is another core, not a disguised variant.

Derive quantity from required coverage, available assets, marginal value and role-hours. Low-resource may combine related questions into one strong core; standard may split them when useful and affordable. Neither scenario is a fixed number of posts per campaign/platform. Mark excluded optional questions and cuts. Every required coverage ID must be covered in each relevant scenario. Avoid repeating the same argument simply to fill a quota.

Each content item has tasks: one research basis per independent core, core production, necessary adaptation, review, delivery and coordination. Include owner or owner-needed, effort range/unit/basis, dates, dependencies, acceptance and upstream output IDs. Shared work counts once; translation/adaptation/review still consumes time. Compare overlapping role-weeks across all campaigns, not people divided by assets. Capacity risk requires cut/merge/move options, not invented FTE.

For regulated or eligibility-sensitive offerings, put actual age/grade/exam-stage requirements and a claim/evidence table in the brief. Hold unsupported claims from public copy. Do not invent courses, teacher credentials, test-center authority, outcomes, prices or CTA routes. The local matrix remains usable when an optional writer is unavailable.
