# Post-Campaign Follow-Up List

A LIST of recommended follow-up items after the campaign ends. List only —
no operations, no how-to, no templates.

The campaign review itself is a separate (future) skill. This skill only lists
what to organize and report, so the review skill has everything it needs.

## Data organization （数据整理）

1. Archive raw data exports (all channels) in one folder per campaign.
2. Reconcile actual spend vs budget (per item).
3. Reconcile actual quantities used vs planned (including wastage).
4. Reconcile actual dates vs planned dates (delays + reasons).
5. Reconcile per-channel conversions (UTM / QR / discount code).
6. Clean the daily log: fill gaps from raw exports; mark unrecoverable items
   as "not collected".
7. Consolidate customer data: new customers, new followers / subscribers,
   reviews collected.
8. File receipts / invoices / timesheets.
9. Archive final creative assets + display / event photos.
10. Log Plan B executions (what happened, what was done, when).

## Reporting （报告）

1. Campaign performance summary (goal vs actual).
2. Per-channel performance table (spend, reach, conversions, cost per result).
3. Cost report (actual vs budget).
4. Timeline adherence report (planned vs actual dates).
5. Materials usage report (produced vs used vs wasted).
6. Customer feedback summary (comments, complaints, reviews).
7. Photo / evidence pack (displays, event photos, key screenshots).
8. Lessons log (brief notes: what worked / what did not — notes only, not the review).
9. Handoff note for the review skill: what data is ready, what is missing,
   where it lives.

## Boundary

- This skill LISTS the items. It does not do the organizing or the reporting.
- The review (analysis, conclusions, recommendations) belongs to a separate
  future skill.
- If an item cannot be completed (e.g. data was not collected), list it as
  missing — do not fabricate it.
