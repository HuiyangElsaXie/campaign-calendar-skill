# 渠道 → 素材套数与产能

套数是范围汇总；物料清单按同一范围逐项列数量、日期与成本依据。创意内容可选交给活动策划（06）/ 文案能力；未安装该 skill 也能完成本 skill 的规划输出。

| 去重后的渠道 / 地点 | 汇总套数 |
|---|---|
| 网站 | 1 套 |
| 实体门店 | 每店 1 套店内素材 |
| 社媒 / 矩阵账号 | 每个唯一账号 1 套平台素材；同一账号不重复计数 |
| 邮件、付费版位、视频、KOL 或其它实际渠道 | 使用时记录渠道与创意范围；不编默认数量 |

只计本活动实际使用的渠道。套数与逐项物料对齐；同一套内的补充物料、适配、语言版本仍可能增加工作。套数**不是小时**，不同渠道也不是可互换的制作单位。

## 产能依据

- 人数仅作背景；需要判断可行性时，再记录瓶颈角色每周粗略可用工时，或使用者确认可比的每周套数。纳入使用者已告知的其它工作；上班时间不自动等于营销可用时间。
- 用同一口径估工作量，并按周合计并行工作，指出角色 / 供应商瓶颈。任何一边未知，都标**产能待确认**，不写“无过载”。
- 复用分为**可直接用**（0 件新增制作）和**需适配 / 审阅**（仍计工作量），逐项说明。没有复用信息时，不假设存在。
- 审批、库存、印刷 / 运输及外包制作可独立限制就绪时间；记录适用依赖，不把同一审批延迟重复计数。
- 资源互不依赖时，时间重叠不必然冲突。产能、迟到及重新确认规则见 lead-time-rules.md。
