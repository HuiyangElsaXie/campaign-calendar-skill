# Mass Sporting Mega-Events (6th candidate source)

Some sporting events are mass-popular (全民性): many industries can run
marketing around them, not just sports brands. Examples: FIFA World Cup
(men's and women's), the Olympics (Summer and Winter), the Super Bowl,
continental championships (e.g. UEFA Euro, Copa América).

## Two modes

- **Brand tie-in (联动)** — a themed campaign riding the event's attention
  (e.g. a "game-night bundle", a watch-party-themed promo, a limited
  event-coloured pack). No physical presence needed.
- **Shop related activities (相关活动)** — a physical shop's own event
  around the mega-event (e.g. an in-store watch party, a game-day tasting,
  extended hours on match days).

## Host-city angle

If the user's city / metro is a host city, the opportunity is stronger:
local foot traffic, visiting fans, watch parties. If not a host city, the
opportunity is national / global awareness tie-in only — say so.

## Date handling

- Mega-event dates are **announced-type (TBC)** — never hardcode them.
  Cycles vary: World Cup every 4 years, Olympics every 2 / 4 years,
  Super Bowl annually. Research the current cycle's dates from official
  sources (federation / organizing committee announcements).
- A mega-event is a **window** (tournament run), not a single day:
  candidate = the window, with the final / key match days as peaks inside it.
  Promo range = the window (or the part of it the user picks). For backwards
  math, D = the promo window start (see `references/lead-time-rules.md`).

## Trademark / IP flag (mandatory)

Every mega-event candidate carries this flag: **do NOT use official logos,
official event names in a way that claims sponsorship, or claim to be an
official sponsor, unless licensed.** Use generic language ("football season",
"the big game", "game night") unless the user holds a license. The skill
flags this; it does not clear legal use.

## Relevance rule (same as all sources)

A mega-event candidate still needs a **specific** reason for THIS user:
host city, audience watches this sport, product fits a watch-party /
celebration context (snacks, drinks, big screens, group gatherings),
or a clear tie-in angle. If no specific reason can be written, the event
does not enter the list (or goes in "Considered but not recommended" with
a one-line reason).
