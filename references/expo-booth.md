# Expo / Event Booth Opportunities (5th candidate source)

Trade shows, expos, conventions, festivals, parades — any event where the brand
can exhibit / set up a booth / run a stall. Researched in Stage 1 (never
pre-built). Examples: anime conventions, baby expos, building-materials expos,
Canada Day parade stalls, large-event stalls.

## Two modes (depends on whether the user gave a city)

- **City given** — only suggestions within that city's range (local expos, stalls).
- **City not given (brand plan)** — surface notable expos in relevant cities as
  brand-exposure prompts: "[City]'s [Event] is a good brand-exposure opportunity."
  Out-of-city expos carry a flag: "factor in travel / logistics."

## Candidate fields (confirmed expos)

- Event name, event date, location.
- **Booth application deadline** — the most critical field. Booths are
  first-come-first-served; missing the deadline means no booth.
- **Booth fee** — if findable, write it; if not, TBC.
- **Permit flag** — stalls may need permits; the user must confirm local
  requirements. The skill does not confirm permits for the user.

Confirmed expo candidates go in the Stage 1 main candidate table, with the
application deadline in the Activity cell, e.g.
"Exhibit at Vancouver Baby Expo (apply by ~Mar 1)".

## Last-year evidence (separate section, never mixed into candidates)

- If no source confirms this year's edition, but last year's edition is found:
  list it in **"Worth further research"** with: event name, last-year date, what
  was found, what the user should verify (this year's date, application
  deadline, booth fee).
- Last year's existence proves the event recurs annually and is worth checking.
  Last year's DATE never proves this year's date.

## After selection

- Timeline gains an extra milestone: **booth application deadline** (before the
  planning deadline).
- Materials checklist gains booth materials: booth display / backdrop, booth
  signage, booth samples, lead capture (QR / form). See
  `references/materials-checklist.md`.
- Format: expo campaigns skip the generic format recommendation — the format IS
  exhibiting. Funnel answers shape booth purpose (sell / sample / lead-gen) and
  booth scale instead.

## Local community events (stall opportunities for local shops / small brands)

Large local community events — Canada Day parades, car-free days
(e.g. Car Free Day Vancouver), cultural festivals (e.g. Chinatown Festival,
Italian Day, Greek Day), neighbourhood street fairs — carry stall
opportunities of their own. Same mechanism as expos (a stall at someone
else's event), but a different profile:

- **Who they are for:** local shops, small businesses, small brands.
  The audience is hyperlocal — the shop's own neighbourhood. For a large
  brand, a local community stall is usually not worth it; if a large brand
  is the user, list local stalls as "Considered but not recommended" with
  that reason (user can overturn).
- **Organizer:** city, BIA (Business Improvement Association), community
  association, or festival committee — not a trade-show organizer.
- **Cost:** often low or free stall fee; sometimes only a permit fee.
  If the fee is not findable, TBC (never invented).
- **Application:** often simpler than a trade expo; sometimes
  first-come-first-served; deadlines may be short / less formal —
  still research the deadline.
- **Permits:** municipal special-event permit; food-vendor permit if
  selling food; insurance sometimes required. The skill flags the permit
  question; the user confirms local requirements.
- **Discovery:** city event calendars, BIA newsletters / listings,
  community-association announcements, municipal special-event listings
  — not expo listing sites. Many local events recur annually
  (Canada Day is annual; car-free days are annual); last-year evidence
  follows the same "Worth further research" rule as expos.

After selection, a local-community stall gets the same treatment as an
expo booth: application-deadline milestone, booth materials, format =
exhibiting (funnel shapes stall purpose / scale).

## Research

Per `references/research-protocol.md`: official expo / event pages, city event
calendars. Confidence tags apply (official-announcement / unverified). Last-year
evidence records its source too.
