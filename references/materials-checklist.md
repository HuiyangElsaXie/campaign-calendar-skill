# Marketing Materials Checklist

Per-campaign annex to the timeline. The timeline says WHEN; this checklist says WHAT,
HOW MANY, and BY WHEN. It does not write the creative.

## Boundary with the campaign planner skill (06)

- This checklist: WHAT + HOW MANY + BY WHEN + cost basis (quantities × unit costs).
- 06 (execution brief): the creative HOW per asset — messaging, design specs, actual copy.
- Copy matrix: this skill decides IF one is needed and counts the copy pieces.
  The matrix CONTENT (the actual copy) belongs to 06 / the copywriting skill.

## Quantities (defaults — user can override any of them)

Defaults are planning defaults, not standards. Every default the user did not confirm
is flagged as a default in the output.

| Channel / item | Default quantity | Notes |
|---|---|---|
| Social account | 2 pieces (feed + story) per account | Per platform. User may change the split. |
| Website | Hero banner + landing banner (1 if no landing page) | |
| Physical store | 2 posters (window + in-store) per store | |
| Copy pieces | 1 core message + 1 per channel adaptation | Counted, not written. Content is 06's job. |
| Copy matrix | Recommended if ≥ 2 platforms / channels | 1 core message × per-platform adaptation. Content is 06's job. |
| Roll-up banner （易拉宝） | 1 per location — ONLY if in-store event / pop-up / 地推 with physical presence | Otherwise: not needed. Never default to yes. |
| Offline distribution posters / flyers | Distribution target + 10% buffer | Only if distribution / 地推. No target → TBC. |
| Small gifts （地推小礼物） | Expected foot traffic × take-rate | Only if 地推 with foot traffic. Both inputs user-supplied; unknown → TBC. Never invent foot traffic or take-rate. |
| QR code / sign-up link | 1 per offline location | Only if offline presence. |

## Use phase

Every item is tagged with when it is used:

- **Warm-up**: teaser / coming-soon pieces (produced first, used from warm-up start).
- **Promo**: offer pieces (used during the promo window).
- **Both**: pieces used across warm-up and promo (e.g. store window poster).

Production deadline already ensures everything is ready by warm-up start (see
`lead-time-rules.md`). The phase tag tells the user which pieces matter first,
not a separate production date.

## Reuse

Assets reused from earlier campaigns are listed with quantity 0 NEW and do not add
production load — list WHAT is reused (product photos, roll-up, talking points, …).
Reuse is decided per campaign in Stage 2 intake (Q12). If the user gave no reuse
info, assume no reuse and say so.

## Conditional questions (intake)

Ask only if applicable — all part of the single intake batch:

- Offline presence? (in-store event / pop-up / 地推 / none) — decides roll-up, flyers, gifts, QR.
- Distribution target (households / people) — decides flyer quantity.
- Expected foot traffic + take-rate — decides gift quantity.
- Unit costs known? (per item) — decides whether the budget table can total.
- Total materials budget cap? — if given, the checklist checks total vs cap and flags overrun.

## Budget worksheet (in the detailed report)

| Item | Quantity | Unit cost | Line total |
|---|---|---|---|
| … | … | user-supplied or TBC | qty × unit cost |

- Unit costs: user-supplied if known, else TBC. NEVER invent prices — print and
  gift costs vary by vendor; the skill does not quote them.
- Without unit costs, the honest output is: "cannot estimate — provide unit costs
  or a budget cap." The checklist's value is the QUANTITY basis: once quantities are
  known, the user prices them in one pass.
- If the user gave a total cap: total vs cap → flag OVER / WITHIN. If total is
  TBC, say the cap check cannot run yet.
- "大概" budget = quantities × user-supplied unit costs (or ranges, if the user
  gives a range). Never a single-point invented total.
- **Total span check:** the budget roll-up checks per-activity totals against
  their budget bands AND the sum of all activities against the total span budget
  (if given). Both checks appear in the detailed report.
