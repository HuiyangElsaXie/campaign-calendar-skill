# 活动形式预设

使用者没有形式想法时的菜单。预设是起点，不是模板——使用者选、混搭，或者用自己的想法覆盖。

如果使用者有想法，就用他的。只有在使用者没有时才给预设。
给预设时，用漏斗（`templates/intake.md` Stage 2 F1–F6 + `references/format-recommendation.md`）——带理由推荐最多 3 种可行形式，然后让使用者选。

| 形式 | 是什么 | 适合什么时候 | 通常需要 |
|---|---|---|---|
| 折扣促销 | 按比例或金额打折，全场或部分产品 | 任何零售大促 | 价格牌、促销海报、折扣码（线上） |
| 组合装 / 礼盒 | 按固定价格搭配成套 | 送礼季（情人节、母亲节、节假日） | 套装包装、套装陈列 |
| 买一送一 | 买 X 送 Y | 清仓、引流 | 货架牌、细则 |
| 新品发布 | 发布 + 发布优惠 | 新品 / 新产品线 | 发布海报、样品、新闻稿 / 公告 |
| 清仓 | 季末 / 尾货清仓 | 换季、库存积压 | 清仓招牌、价格牌 |
| 快闪 / 店内活动 | 带体验的线下活动 | 有线下实体、发布、节假日 | 易拉宝、装饰、员工、打卡墙 |
| 试吃 / 试用 | 店内或地推试吃 / 试用 | 食品 / 饮料 / 美妆、新品 | 样品、试吃用品、员工 |
| 满赠 | 满门槛送礼 | 提高客单价 | 礼品、门槛招牌、细则 |
| 集点 / 会员 | 集点卡或会员推广 | 重复到店 | 集点卡、台卡 |
| 抽奖 | 抽奖换互动 | 引流 + UGC + 涨粉 | 奖品、抽奖规则、细则 |
| 预售 / 预约 | 预售带早鸟优惠 | 库存有限、发布 | 预售页面 / 表单、早鸟条款 |
| 联名 / 合作 | 和另一个品牌或 KOL 合作 | 扩大客群 | 合作方物料、KOL 物料包 |

## 规则

- 预设永远不决定大促日期范围、预算或渠道——那些来自 Stage 2 intake。
- 预设可能增加物料（例如试吃 → 样品；快闪 → 易拉宝）。物料清单会自动接上。
- 不要把预设说成“最佳实践”或效果承诺。它们是形式选项，不是经验证有效的赢家。
