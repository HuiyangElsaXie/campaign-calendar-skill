# Contingency Plan B — Disruptions & Pre-Decided Responses

Principle: a Plan B only works if it is decided BEFORE the campaign. At Gate 2
(timeline confirmation), the user pre-decides the items in the "Decide BEFORE"
column and names a Plan B decision-maker (intake item) — the one person who can
authorize a Plan B during the campaign without waiting for a meeting.

This skill does NOT monitor the campaign live. The user / decision-maker watches
for the signals and executes the Plan B.

## Pre-decide at Gate 2 (checklist)

- Rain date / indoor backup (outdoor events)
- Price floor — the lowest price / deepest discount allowed, never crossed in a panic
- Discount-code caps (max redemptions) + kill switch (who can disable a code)
- Dynamic QR / short links (destination changeable without reprinting)
- Backup roster (who covers if someone is sick)
- Holding statement for complaints (one paragraph, approved in advance)
- Plan B decision-maker (one name)

## Situations

| Situation | Signal | Plan B | Decide BEFORE |
|---|---|---|---|
| Bad weather (outdoor / 地推） | Forecast turns / rain on the day | Move indoors, switch to online-only, or use rain date | Rain date + indoor backup |
| Low turnout / traffic far below expected | Foot traffic / clicks well under plan by mid-campaign | Social + email blast, staff street outreach, boost post (if budget), extend promo | Who can authorize a boost / extension |
| Stock-out: promo product sells out | Inventory hits zero | Substitute product, raincheck / pre-order, extend promo to restock date, update ALL channels at once (website + social + store signage) | Substitute product + restock date source |
| Website / QR / link down | QR scans drop to zero / error reports | Switch to backup link (dynamic QR), post notice, extend promo by the downtime | Dynamic QR + backup link |
| Printing delay / materials not ready | Printer misses delivery date | Digital-first fallback (social + email + handwritten in-store signs), delay launch, print only essentials | Which materials are essential vs nice-to-have |
| Staff shortage | Call-in sick / no-show | Backup roster, simplify in-store setup, reduce hours | Backup roster |
| Social post removed / account restricted | Post disappears / account notice | Backup account, fall back to email + website, appeal | Backup account exists |
| Negative feedback going viral | Complaint post gaining traction | Acknowledge publicly within hours, take it offline (DM / phone), do not delete comments, use holding statement | Holding statement + who responds |
| Competitor launches same-day promo | Competitor announcement | Hold — differentiate on value, not price. Never panic-discount below the price floor | Price floor |
| Discount-code leak / abuse | Redemptions spike beyond the intended audience | Cap redemptions, switch to single-use codes, disable the leaked code, honor already-redeemed | Code caps + kill switch |
| POS / checkout down | Transactions failing | Cash-only fallback (in-store), manual order form (online), extend promo | Cash float + manual form ready |
| Influencer / KOL no-show or late | Missed posting time | Publish backup owned content, reschedule, use pre-prepared content | Content ready in advance |
| Gifts / samples run out | Giveaway stock hits zero | Substitute, raincheck, cap 1 per customer (pre-decided) | Per-customer cap |
| Venue / permit issue | Venue cancels / permit denied | Backup venue, go online-only, reschedule | Backup venue |
| Booth application rejected / no booth granted | Organizer declines the application | Fall back to brand tie-in without a physical stall: online promo + local flyering / partner-shop pop-up; or apply to a different local event | Backup local event / online fallback pre-decided |
| Mega-event postponed / cancelled | Organizer announcement | Decouple the campaign from the event: switch to the generic angle (e.g. "football season" → "summer game night"); keep the promo, drop event-specific claims | Generic fallback angle pre-decided |
| Data not collected | Daily log empty for 2+ days | Collector catches up same day from raw exports; if unrecoverable, mark "not collected" — never reconstruct from memory | Daily collector named |

## Boundary

- Plan B is prompts + pre-decisions, not a guarantee. The skill cannot prevent disruptions.
- If a Plan B is executed, log it in the daily log (what happened, what was done,
  when) — it becomes part of the review's "what did not go to plan" section.
