# Activity Format Presets

A menu for when the user has no format idea. Presets are starting points, not
templates — the user picks, mixes, or overrides with their own idea.

If the user HAS an idea, use it. Only offer presets when they don't.
When offering, use the funnel (`templates/intake.md` Stage 2 F1–F6 +
`references/format-recommendation.md`) — suggest 2–3 with reasons, then let the
user pick.

| Format | What it is | Fits when | Typically needs |
|---|---|---|---|
| Discount sale （折扣促销） | % off or $ off, storewide or selected products | Any retail promo | Price tags, promo posters, code (if online) |
| Bundle / gift set （组合装 / 礼盒） | Curated sets at a set price | Gifting seasons (Valentine's, Mother's Day, holidays) | Set packaging, set display |
| BOGO （买一送一） | Buy X get Y | Clearance, traffic driving | Shelf tags, T&Cs |
| New product launch （新品发布） | Launch + launch offer | New product / new line | Launch posters, samples, press / announcement |
| Clearance （清仓） | End-of-line / seasonal clearance | Season change, overstock | Clearance signage, price tags |
| Pop-up / in-store event （快闪 / 店内活动） | Physical event with experience | Offline presence, launches, holidays | Roll-up, decor, staff, photo wall |
| Tasting / sampling （试吃 / 试用） | In-store or ground sampling | Food / beverage / beauty, new products | Samples, tasting supplies, staff |
| Gift with purchase （满赠） | Free gift over a threshold | Raising basket size | Gifts, threshold signage, T&Cs |
| Loyalty / stamp card （集点 / 会员） | Stamp card or loyalty push | Repeat visits | Stamp cards, counter cards |
| Giveaway / lucky draw （抽奖） | Prize draw for engagement | Traffic + UGC + followers | Prizes, draw rules, T&Cs |
| Pre-order / reservation （预售 / 预约） | Pre-order with early-bird perk | Limited stock, launches | Pre-order page / form, early-bird terms |
| Collaboration / co-brand （联名 / 合作） | With another brand or KOL | Audience expansion | Partner assets, KOL kit |

## Rules

- Presets never dictate the promo date range, budget, or channels — those come
  from Stage 2 intake.
- A preset may ADD materials (e.g. tasting → samples; pop-up → roll-up).
  The materials checklist picks those up automatically.
- Do not present presets as "best practices" or performance promises.
  They are format options, not proven winners.
