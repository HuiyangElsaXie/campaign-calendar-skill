# 活动后跟进清单

活动结束后建议做的跟进事项清单。只列项——不写操作、不写方法、不给模板。

活动复盘本身是另外一个（未来的）skill。本 skill 只列出要整理什么和报告什么，让复盘 skill 拿到它需要的一切。

## 数据整理

1. 把原始数据导出（所有渠道）归档到一个活动一个文件夹。
2. 核对实际花费 vs 预算（按项）。
3. 核对实际用量 vs 计划用量（包括损耗）。
4. 核对实际日期 vs 计划日期（延误 + 原因）。
5. 核对分渠道转化（UTM / QR / 折扣码）。
6. 清理每日日志：从原始导出补空缺；无法补回的标为“not collected”。
7. 汇总客户数据：新客户、新增粉丝 / 订阅、收集到的评价。
8. 归档收据 / 发票 / 工时表。
9. 归档最终创意物料 + 陈列 / 活动照片。
10. 记录 Plan B 执行情况（发生了什么、做了什么、什么时候）。

## 报告

1. 活动效果总结（目标 vs 实际）。
2. 分渠道效果表（花费、触达、转化、每结果成本）。
3. 成本报告（实际 vs 预算）。
4. 时间线遵守报告（计划日期 vs 实际日期）。
5. 物料使用报告（制作 vs 使用 vs 浪费）。
6. 客户反馈总结（评论、投诉、评价）。
7. 照片 / 证据包（陈列、活动照片、关键截图）。
8. 经验记录（简短备注：什么有效 / 什么没效——只是备注，不是复盘）。
9. 给复盘 skill 的交接备注：哪些数据已准备好、哪些缺失、都在哪里。

## 边界

- 本 skill 只列出事项。它不做整理或报告。
- 复盘（分析、结论、建议）属于另外一个未来的 skill。
- 如果某项完成不了（例如数据没收集），就列为缺失——不要编造。
