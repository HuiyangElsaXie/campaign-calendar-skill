# Campaign Calendar Skill（活动日历）

> 版本 1.0 — 2026-10-17 验收通过。
> 维护修订 1.0.1 — 日期、倒推、成本、产能与表单修复（2026-10-18）。

为使用者自己定义的时间跨度做活动时间线 + 日历——可以是一个临时活动、一个季度、
一个季节，也可以是一整年。以大促日为锚点，往前倒推企划、物料制作、宣发截止日。

## Inputs（输入，分两阶段）

**第一阶段（用于推荐活动）：**
- 国家（6 个现成层：Canada、中国、美国、英国、日本、韩国；其他 → 按研究协议现搜）
- 时间跨度（开始–结束日期，使用者自己定）
- 卖什么（产品 / 服务品类）
- 卖给谁（目标客户 + 文化背景）
- 什么时候买 / 用（使用季 / 购买周期、高峰、有没有季前）
- 品牌 / 自定日期（可没有）
- 城市 / 都市区（选填——填了按本地给展位 / 社区摆摊建议 + 主办城市体育盛会，没填按品牌模式）
- 上次活动（选填——上次/去年做了什么、效果、实际提前量）
- 已知竞品活动 / 日期（选填）

**第二阶段（选定活动后，逐个活动填）：**
- 渠道与产能（网站、门店数、社媒账号数、矩阵账号）
- 提前量：企划、制作时长、预热与一次交付缓冲（缺失则范围 + 假设）
- 预算币种、成本范围与明确上限（物料小计区别于全活动 / 总跨度成本）
- 人数 + 审批链；需要时再问可用工时 / 吞吐量，否则产能待确认
- 每个活动：大促日期范围 · 漏斗 F1–F6 → 形式推荐 · 人流估算（线下才问）· 复用

## Outputs（输出）

**第一阶段——活动推荐报告**（简单 + 可交互）：时间跨度内的候选活动 + 使用者下一步要决定的事（选活动 + 填第二阶段详情）。还没有倒推计算、物料、预算、时间线。

**第二阶段——最终输出（按此顺序）：**

1. **时间线**——按时间排序：每个活动的企划截止、制作开始、预热开始、大促日期。主干。每个活动带三个附件：**物料清单**（产出什么 + 多少 + 何时要）、**数据收集清单**（活动过程中收集 + 留存什么，供复盘用）、**突发情况 Plan B**（常见意外的预先应对方案）。
2. **活动日历**——同一份数据以日历形式呈现 + 即将到期节点提醒清单。
3. **具体报告**——给老板的计划文档：目标、活动总览、里程碑、产能依据 / 状态 + **成本范围**（物料小计及其它必要成本；完整且同范围才核对上限，不编价）+ 必带的假设与未知日志。

## How to Use / Execution Flow（怎么用）

**第一阶段——推荐：**
1. **你**提供轻量 intake：国家、时间跨度、卖什么、卖给谁、什么时候买 / 用、品牌日期（见 `templates/intake.md` Stage 1）。
2. **AI**根据国家层 + 客群文化层 + 季节锚点 + 你的日期 + 展位 / 本地社区摆摊机会 + 全民性体育盛会 + 使用者自添加候选，相关性推理（上次活动校准提前量），生成候选活动推荐报告。
3. **你决策（关口 1——选活动）**：选出要做的活动 + 逐个填 Stage 2 详情（大促范围、漏斗 F1–F6、人流、复用）。

**第二阶段——做计划：**
4. **AI**经漏斗推荐形式，套用提前量和渠道套数，倒推计算，做迟到检查 + 按人力产能的冲突与过载检查，给取舍建议。
5. **你决策（关口 2）**：确认时间线（可调日期 / 优先级）。
6. **AI**按顺序输出：时间线 → 活动日历 → 具体报告。
7. **你**把提醒清单导入自己的日历工具。本 skill 不发布、不排期、不花钱。

人的决策点：做哪些活动、每个活动的详情（范围、线上 / 线下、预算、形式）、哪些活动必做 / 可砍、时间线最终确认。AI 做推荐、日期计算、冲突检查和起草。

活动结束后：附一份活动后跟进清单（推荐的数据整理 + 报告项目，只列项、不写操作）。复盘本身是另外一个未来的 skill。

## Honesty rules（诚实规则）

不编造日期。预估一律是范围 + 标注假设。未知是合法答案。不承诺效果。未获确认的输出 = 草稿，不是批准的计划。

## License（许可）

待定——非商用方向。不用 MIT（MIT 允许商用，与作者非商用意向冲突）。

## 语言（Languages）

本 repo 每个 `.md` 文件都有一个 `.zh-CN.md` 中文版（内容相同）。**输出语言：** skill 在调用时问输出用英文还是中文，并读取对应语言版本的文件。

## 运行环境

对话框 agent —— 不需要写代码 / 搭建类 agent。要求联网研究（完整功能）+ PDF 输出（第二阶段可视化报告）。离线回退：现成层 + 未验证标签。无 PDF 回退：Markdown + HTML 打印成 PDF。（第一阶段报告是 Markdown / 对话原生，不需要 PDF。）
